PRATYAKSH PATEL — STUDENT PORTFOLIO

Files:
- index.html: page content
- style.css: layout, colors and responsive styling
- script.js: mobile navigation and current year
- images/profile.jpg: profile photo

How to preview:
1. Open this folder in VS Code.
2. Open index.html in your browser, or use the Live Server extension.

Before publishing:
- Check the email and phone number.
- Add your own projects when you have them.
- Confirm the education details and certificate title.
- To change the profile photo, replace images/profile.jpg with your image and keep the same filename.

Built with HTML, CSS and vanilla JavaScript.
